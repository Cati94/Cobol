# 🦖 COBOL: O Dinossauro Simpático

Um olhar lúdico sobre a linguagem **COBOL**, muitas vezes chamada de “dinossauro” da programação, mas ainda viva em muitos sistemas.

## 🦕 Ilustração Vintage

![Dinossauro programador COBOL](https://github.com/Cati94/Cobol/blob/main/dino_cobol.png.png)

Um dinossauro feito de cartões perfurados, sentado num antigo computador, programando tranquilamente — um símbolo acolhedor do legado da computação.

## 🎯 Objetivos

Este repositório tem como propósito:

- 📚 Explorar a **sintaxe e estrutura** da linguagem COBOL
- 🏦 Entender seu uso em **sistemas bancários e legados**
- 💻 Praticar a criação de programas COBOL básicos:
  - `Hello World`
  - Cadastros simples
  - Geração de relatórios
  - Estruturas de controle e processamento de dados

---

## 📁 Arquivos do Projeto

| Arquivo                      | Descrição                                 |
|-----------------------------|-------------------------------------------|
| `HelloWorld.cbl`            | Um exemplo básico de "Hello, World"       |
| `hello world in cobol.cob`  | Variante alternativa do mesmo exemplo      |
| `paylod.cbl`                | Exemplo com estrutura condicional ou lógica mais avançada |
| `hello world basic.vb`      | Comparativo com outra linguagem (VB)       |
| `dino_cobol.png.png`        | Ilustração simbólica do projeto            |

## ▶️ Executando o Código

### Pré-requisitos:
- [GnuCOBOL](https://gnucobol.sourceforge.io/) instalado no sistema

```bash
